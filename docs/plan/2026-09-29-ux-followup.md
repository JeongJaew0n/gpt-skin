# UX 후속 작업 — 진행 계획

2026-09-29 · 근거: [UX 조사 — 세 번 되풀이](2026-09-28-ux-research.md) · 시작 버전 0.12.1

조사의 A1(esc 버그)은 0.12.1 에서 고쳤다([이슈](../issue/2026-09-29-esc-stops-generation.md)).
남은 A2~A5 · B1~B6 을 다섯 묶음으로 나눠 차례로 한다. 묶음 하나가 끝날 때마다 테스트 → 수정 → 테스트를 거쳐 커밋·푸시한다.

---

## 결정 — 묻지 않고 정한 가정

조사 문서 §5 의 결정 셋은 사용자에게 묻지 않고(요청: "묻지 말고 진행") **되돌리기 쉬운 쪽**으로 정했다.
바꾸려면 이 표만 고치고 해당 묶음을 다시 하면 된다.

| 결정 | 가정 | 이유 |
|---|---|---|
| 시트는 모양인가 위장인가 | **모양.** 탭 제목 · 파비콘은 바꾸지 않는다 | 위장은 원본 React 와 제목을 두고 싸우게 된다 `[가정]`. 안 하는 쪽이 되돌릴 게 없다 |
| `enabled` 와 `skin: none` 을 합치나 | **합치지 않는다** | 팝업 토글의 뜻이 바뀌고 저장값 이관이 필요하다 |
| 맥 입력줄의 `Ctrl+B` | **그대로 둔다.** ⌘/Ctrl+⇧S 를 더한다 | 기존 손버릇을 빼앗지 않는다. 더하는 쪽은 부작용이 없다 |

## 묶음별 설계

### 1 — 작은 것 넷

- **A2 경고 상태 문구** — 콘텐츠 스크립트의 `state` 응답에 `warned` · `reasons` 를 더한다. 팝업은 경고가 있으면
  도움말 줄에 "경고 N개 — 첫 경고 · :health 로 전체" 를 쓴다. 복귀(빨강) 문구는 그대로.
- **A3 시트 커서** — `@media (prefers-reduced-motion: reduce)` 에서 `.gs-caret` 애니메이션을 끈다.
- **A4 단축키 표기** — `GT_MOD()` 를 공용(i18n.js)에 둔다: 맥이면 `⌘`, 아니면 `Ctrl+`. 터미널 상태줄 안내와
  팔레트 푸터가 쓴다. 판별: `navigator.userAgentData.platform` → 없으면 `navigator.platform`.
- **A5 생성 상태 알림** — 스킨 루트에 눈에 안 보이는 `role=status` 요소 하나. 생성이 시작되면 "응답 중",
  끝나면 "응답 완료" 만 쓴다. 토큰마다 쓰지 않는다(스크린리더가 망가진다 — 조사 §1.2). 계약을 늘리지 않고
  `GT.skin.announce(text)` 가 `overlayRoot()` 안에 요소를 둔다.

### 2 — 단축키

- **토글 키** — `e.key === '`'` → `e.code === 'Backquote'`. 맥 한글 입력에서 이 키는 ₩ 를 낸다.
- **⌘/Ctrl+⇧S** — 사이드바 여닫기. 원본 ChatGPT 와 같은 키 `[가정: 웹 자료]`. 스킨이 보일 때만 가로챈다.
- **`chrome.commands`** — `toggle-skin` 명령을 기본 키 없이 등록한다. 사용자가 `chrome://extensions/shortcuts`
  에서 원하는 키를 준다. 서비스 워커가 `onCommand` 를 받아 활성 탭에 `toggle` 을 보낸다(팝업 토글과 같은 경로).
  기본 키를 주지 않는 이유: 허용 키(영문 · 숫자 · 일부)는 원본 · 브라우저 · 운영체제와 겹칠 수 있고 실측하지 못했다.
- **팝업** — 푸터에 '단축키' 링크. `chrome.tabs.create({ url: 'chrome://extensions/shortcuts' })` 는 확장 페이지에서 허용된다.

### 3 — 팔레트

- 팔레트 항목에 대화를 더한다(`GT.chats.state` — 이미 읽어 둔 목록, 새 요청 없음).
  - 입력이 비었거나 `:` 로 시작하지 않으면: 대화 + 명령을 함께 퍼지 검색. 대화가 위.
  - `:` 로 시작하면: 명령만.
  - 대화를 고르면 `GT.navigate.to(href)`. 명령을 고르면 지금처럼 입력줄에 채운다.
- 명령 옆 단축키: `:sidebar` → `⌘⇧S`, `:new` → 없음 등. 명령 정의에 `keys` 를 붙이지 않고 팔레트가 작은 표를 든다.
- 팝업에 '명령 열기 ⌘K' — 탭에 `palette` 를 보내면 스킨을 켜고 팔레트를 연다.

### 4 — 흐름

- **B4 새 응답 알림** — 렌더 때 바닥에 붙어 있지 않은데(`stickBottom` 거짓) 내용이 바뀌면 "↓ 새 응답" 을 띄운다.
  터미널은 상태줄, 시트는 상태 표시줄. 누르거나 바닥까지 스크롤하면 사라진다.
- **B5 시트 메시지 복사** — 행 번호 칸을 누르면 그 메시지의 행을 모두 고른다. ⌘/Ctrl+C 는 메시지 원문(마크다운)을
  복사한다. 셀을 고른 상태의 ⌘C 는 지금처럼 셀 글자.
- **B6 진단 복사** — 팝업 버튼. 탭에 `diag` 를 보내면 콘텐츠 스크립트가 버전 · 빌드 · 스킨 · 보임 상태 · 점검
  결과 · 경고를 한 덩어리 글로 돌려준다. **대화 제목 · 본문 · 주소는 넣지 않는다**(개인정보처리방침).

### 5 — 첫 실행

- `onInstalled` 의 `install` 갈래에서만 `src/welcome/welcome.html` 을 연다. 업데이트 때는 열지 않는다.
- 한 장, 할 일 하나: "ChatGPT 를 열고 Ctrl+` (맥 ⌘ 표기 포함)". 스킨 셋 설명 한 줄씩, 팝업 위치 안내.
- 문구는 사전(ko · en). 이모지 없음. 패키지에 포함(`src/` 아래).

## 검증

- 단위 테스트: 새 검사는 일부러 깨뜨려 실패하는지 본다(CLAUDE.md §5).
- 브라우저: 하네스(`tools/harness/`)로 팔레트 · 새 응답 알림 · 시트 복사 · 환영 페이지를 본다.
  실제 ChatGPT 확인은 확장을 다시 로드한 뒤(`:reload`).
- 원본 동작에 기대는 것(⌘⇧S 가 원본에서 무엇을 하나)은 `[가정]` 으로 두고 확인 방법을 적는다.
