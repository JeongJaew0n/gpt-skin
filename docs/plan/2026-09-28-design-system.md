# 확장 UI 디자인 시스템 — 조합 57 "놀라운 깔끔함"

작성: 2026-09-28 · 0.12.0

---

## 1. 왜

팝업과 설정 화면은 GitHub 다크 터미널 팔레트(`#0d1117` 바탕, `#3fb950` 초록)에 고정폭 글꼴, 네모 스위치,
`❯` 화살표, `[×]` 체크, `CONFIG` 모드 표시로 되어 있었다. terminal 스킨에는 맞지만 sheet · none 스킨을
쓰는 사람에게는 겉돈다. 다크 한 벌뿐이라 브라우저를 라이트로 써도 팝업이 검게 떴다.

확장 UI 는 **어느 스킨을 쓰든 어울리는 범용 모양**이어야 한다. 채팅 화면 위의 스킨과는 별개다.

## 2. 범위

| 대상 | 이번에 바꿈 |
|---|---|
| 팝업 `src/popup/` | 바꿈 |
| 설정 화면 `src/options/` | 바꿈 |
| 채팅 화면 스킨 (terminal · sheet · none) | 안 바꿈 — 스킨은 각자 모양이 있다 |

## 3. 팔레트

Figma 「다음 디자인에 영향을 줄 100가지 색상 조합」의 **조합 57 놀라운 깔끔함 (Quite clear)**.
원본 hex 는 조합 이미지에 적힌 값이다 `[확정]`.

```
#CBCBCB  #F2F2F2  #174D38  #4D1717
회색      밝은 회색  짙은 초록   짙은 빨강
```

고른 이유: 팝업이 색에 담는 뜻은 둘뿐이다 — **켜짐 = 초록, 고장 = 빨강**. 이 조합은 그 두 색이 이미 들어 있어
뜻을 바꾸지 않고 터미널 느낌만 걷어낼 수 있다. 후보 6개 비교는 아티팩트
(https://claude.ai/artifact/6VxDtNeMVCnaRjgmKeqQVA, 비공개)에 있다.

### 원본과 파생

팔레트 네 색만으로는 글자색 · 다크 테마를 만들 수 없어 나머지는 맞춰 만들었다. `ds.css` 주석에 한 줄씩 적었다.

- **원본을 그대로 쓴 곳**: 라이트 바탕 `#F2F2F2` · 구분선 `#CBCBCB` · 강조 `#174D38` · 진한 위험 `#4D1717`,
  다크 글자 `#F2F2F2` · 다크 보조 글자 `#CBCBCB`
- **원본을 바꾼 곳**: 위험색. `#4D1717` 은 8px 점이나 작은 글자에서 검정과 구분되지 않아 `#8F2424` 로 밝혔다.
  원본은 `--ds-danger-deep` 으로 남겼다
- **다크 테마**: 강조 `#174D38` 은 다크 바탕에서 안 보여 `#5FB38D` 로 밝혔다. 바탕은 강조색 쪽으로 살짝 기운 검정

## 4. 토큰 (`src/shared/ds.css`)

이름은 `--ds-*`. 화면 CSS 는 토큰만 쓰고 색을 직접 적지 않는다.

### 색 — 역할로 이름 짓는다

| 토큰 | 역할 | 라이트 | 다크 |
|---|---|---|---|
| `--ds-bg` | 화면 바탕 | `#F2F2F2` 원본 | `#131715` |
| `--ds-surface` | 카드 · 상단바 · 입력칸 | `#FFFFFF` | `#1B201D` |
| `--ds-sunken` | 세그먼트 바닥 · 단축키 | `#E8E8E8` | `#242A26` |
| `--ds-line` | 구분선 (장식) | `#CBCBCB` 원본 | `#2E3531` |
| `--ds-line-strong` | 입력칸 테두리 · 꺼진 스위치 | `#7C827E` | `#6E7671` |
| `--ds-text` | 본문 · 라벨 | `#1F2421` | `#F2F2F2` 원본 |
| `--ds-text-2` | 도움말 | `#4F5652` | `#CBCBCB` 원본 |
| `--ds-text-3` | 가장 흐린 글자 | `#5E6561` | `#9AA19D` |
| `--ds-accent` | 켜짐 · 선택 · 초점 | `#174D38` 원본 | `#5FB38D` |
| `--ds-accent-soft` | 선택된 항목 바탕 | `#E2EDE7` | `#1D3A2D` |
| `--ds-on-accent` | 강조색 위 글자 | `#FFFFFF` | `#0E1A14` |
| `--ds-danger` | 고장 · 초기화 | `#8F2424` | `#E08A8A` |
| `--ds-danger-deep` | 진한 위험 | `#4D1717` 원본 | `#B85C5C` |
| `--ds-danger-soft` | 경고 줄 바탕 | `#F6E7E7` | `#3A2020` |

경고(노랑)는 두지 않았다. 예전 설정 화면은 "기본값과 다름" 을 노랑으로 표시했는데, 이건 경고가 아니라 상태라
강조색 점으로 바꿨다. 색 수를 늘리지 않는다.

### 대비 (계산값) `[확정 — 계산]`

기준: 글자 4.5:1(WCAG 1.4.3), 입력칸 테두리 같은 UI 3:1(WCAG 1.4.11). 이 화면은 11~12px 글씨가 대부분이라
흐린 글자도 4.5:1 을 넘긴다 — 예전에 도움말이 2.3:1 까지 떨어져 안 읽혔다.

| | 라이트 (bg `#F2F2F2`) | 다크 (bg `#131715`) |
|---|---|---|
| text | 14.1 | 16.2 |
| text-2 | 6.7 | 11.2 |
| text-3 | 5.3 (sunken 위 4.9) | 6.9 (sunken 위 5.6) |
| accent | 8.7 | 7.2 |
| danger | 7.7 | 7.0 |
| line-strong | 3.5 | 3.9 |
| on-accent / accent | 9.7 | 7.1 |

실제 크롬 팝업에서 눈으로 본 것은 아니다 `[미정]` — ↻ 후 팝업과 설정 화면을 라이트 · 다크에서 한 번씩 열어 본다.

### 글꼴

- 본문: 시스템 산세리프 (`-apple-system`, Pretendard, Apple SD Gothic Neo, Segoe UI, 맑은 고딕 …)
- 값: 시스템 고정폭 — **단축키 · 설정 키 이름 · 빌드 시각에만** 쓴다
- **웹폰트를 불러오지 않는다.** 웹스토어 점검(`tools/package.sh`, `test/store.listing.test.mjs`)이 `src/` 의
  외부 주소를 막는다. 설치된 Pretendard 가 있으면 쓰고 없으면 시스템 글꼴로 떨어진다

### 크기 · 간격 · 모서리

| | 값 |
|---|---|
| 글자 | xs 11 · sm 12 · md 13 · lg 15 · xl 18 — 이 다섯만 |
| 간격 | 4px 단위 — 4 · 8 · 12 · 16 · 20 · 24 · 32 |
| 모서리 | sm 4 (단축키 · 배지) · md 6 (입력칸 · 세그먼트) · lg 10 (카드) · pill (스위치 · 점) |
| 움직임 | 120ms. `prefers-reduced-motion` 이면 0 |

### 테마 전환

`prefers-color-scheme` 을 따른다. 따로 고르는 설정은 두지 않았다 — 필요하면 나중에 설정 항목으로 더한다.

## 5. 부품 (`.ds-*`)

| 부품 | 쓰는 곳 | 모양 |
|---|---|---|
| `.ds-dot` | 팝업 · 설정 상단 | 8px 원. `data-on="1"` 강조, `data-broken="1"` 위험 (고장이 이긴다) |
| `.ds-switch` | 팝업 토글 | 둥근 스위치. `data-on` 으로 켜짐. 누르는 것은 줄 전체(버튼) |
| `.ds-check` | 설정 bool 항목 | 진짜 checkbox + `.ds-switch` 모양 + 켜짐/꺼짐 글자 |
| `.ds-seg` / `.ds-seg__item` | 팝업 스킨 고르기 | 세그먼트. 고른 항목은 흰 면 + 강조색 글자 |
| `.ds-input` / `.ds-select` | 설정 입력칸 · 선택 상자 | 6px 모서리. 초점이면 강조 테두리 + 옅은 링 |
| `.ds-kbd` | 단축키 · 키 이름 | 고정폭, sunken 바탕 |
| `.ds-link` (`--danger`) | 설정 전체 · 기본값 · 전체 초기화 | 글자 버튼. 위험 동작은 hover 에 빨강 |
| `.ds-badge` (`--accent`, `--danger`) | "저장됨" | 둥근 짧은 상태 글자 |

초점은 모두 `:focus-visible` 에 강조색 2px 링.

## 6. 화면별로 바뀐 것

### 팝업

- 바탕 · 상단바 · 푸터를 토큰으로. 상단바와 푸터는 흰 면, 본문은 회색 바탕
- 스킨 버튼 줄 → `.ds-seg`
- 네모 스위치 → `.ds-switch`
- 고장 상태의 도움말을 위험색으로 (`row[data-broken]`)

### 설정 화면

- `:config — chrome.storage.sync` 제목 → "설정" (사전 `opt.ui.title`)
- 구역 목록의 `❯` · 왼쪽 초록 막대 → 둥근 선택 바탕(`accent-soft`)
- `SECTIONS` → "구역" (사전 `opt.ui.sections`)
- 한 구역의 항목을 카드 하나로 묶었다 (첫 줄 위 모서리, 마지막 줄 아래 모서리)
- `[×] on` / `[ ] off` → 체크 스위치 + "켜짐" / "꺼짐" (사전 `opt.ui.on` · `opt.ui.off`)
- 기본값과 다른 항목의 노란 `●` → 강조색 점
- 하단 `CONFIG` 모드 표시 제거. 전체 초기화는 위험 글자 버튼
- 좁은 창(760px 미만)에서는 구역 목록을 숨기고 항목을 한 줄로 쌓는다

## 7. 규칙

- 화면 CSS(`popup.css` · `options.css`)에 색을 직접 적지 않는다. 필요한 색이 없으면 `ds.css` 에 토큰을 더한다
- 새 부품은 `ds.css` 에 `.ds-` 로 만든다. 한 화면에서만 쓰는 배치는 화면 CSS 에 둔다
- 글자 크기 · 간격은 토큰 값만 쓴다

## 8. 확인하지 않은 것 `[미정]`

- 실제 크롬 팝업 · 설정 화면에서 라이트 · 다크로 본 모양 — ↻ 후 열어 본다
- `.row:has(+ h2)` 로 카드 아래 모서리를 둥글린다. 크롬 105 부터 되는 선택자라 지금 크롬(153)에서는 된다고 보지만 화면으로 보지 않았다

## 9. 회귀 방지 — `test/popup.test.mjs`

- `ds.css` 의 라이트 · 다크 토큰을 둘 다 읽어 글자 4.5:1 · 입력칸 테두리 3:1 · 강조색 위 글자 4.5:1 을 검사한다
- 팝업이 `ds.css` 를 `popup.css` 보다 먼저 불러오는가 · `popup.css` 에 색을 직접 적지 않았는가

일부러 깨뜨려 확인했다: 라이트 `text-3` 을 `#A0A0A0` 으로 → 3건 실패, 다크 강조색을 원본 `#174D38` 로 → 3건 실패,
`popup.css` 에 hex 한 줄 → 1건 실패. 전체 `tools/test.sh` 1578건 통과.
