작성 · 구현: 2026-10-02 · 0.25.0

## 무엇이 바뀌나

| | 0.24 까지 (`:chats`) | 0.25.0 |
|---|---|---|
| 탭에 뜨는 것 | 대화 목록 API 의 최근 대화 40개 전부 | **내가 연 대화만** |

## 구조

- `src/content/tabs.js` — `GT.tabs`. `[{ id, href, title, seen }]`
  - `open(path, title)` 대화를 열면 끝에 넣는다(있으면 본 시각만). 새 대화 화면(`/`)은 넣지 않는다
  - `title(id, text)` 제목은 대화 원본을 읽은 뒤에 들어온다
  - `close(id)` 오른쪽(없으면 왼쪽) 탭을 돌려준다 — 지금 탭을 닫으면 거기로 간다. 남은 탭이 없으면 새 대화
  - `step(dir)` / `go(dir)` 끝에서 넘어가면 반대쪽 끝. 지금 대화가 탭에 없으면(새 대화 화면) 첫 · 끝 탭
  - 최대 20개. 넘치면 가장 오래 안 본 탭부터 닫는다
  - 프로젝트 안의 대화(`/g/<프로젝트>/c/<id>`)도 — id 는 `/c/` 뒤, href 는 주소 그대로
- `index.js` — 부팅 때 저장된 탭을 읽고 지금 대화를 넣는다. 600ms 라우팅 감시에서 주소가 바뀌면 `open`. 제목이 들어오면 `title`.
  탭이 바뀌면 상단(탭 줄)을 다시 그린다
- 터미널(위쪽) · 시트(아래쪽) 탭 줄이 같은 목록을 그린다 — 스킨을 바꿔도 탭이 그대로다. `:chats` 는 탭 줄을 보이거나 숨긴다(기본 숨김 —
  숨기면 지금 대화 탭만)
- `Ctrl+,` / `Ctrl+.` — 물리 키(`Comma` · `Period`)로, 조합 가드 앞에서 본다(한글 상태). `⌘,` 는 브라우저 설정 키라 건드리지 않는다.
  스킨이 꺼져 있으면 원본에 맡긴다

## 저장 위치

`local` 을 쓴다. `sync` 는 대화 id 와 제목이 구글 계정 동기화로 올라간다.
