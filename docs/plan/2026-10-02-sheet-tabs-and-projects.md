# sheet 대화 탭 숨기기 · 터미널 · 시트에서 프로젝트 보이기

작성 · 구현: 2026-10-02 · 0.21.0

## 1. sheet 에서 대화 목록 숨기기

**지금** `[확정 — 코드]`: 아래쪽 시트 탭 줄이 대화 목록이다. 부팅 때 목록 API 를 읽어 다른 대화를 최대 40개 탭으로 늘어놓았다.

**바꾼 것**
- 설정 `sheet.chatTabs` (bool, 시트 전용, **기본 끔**)
- 끄면 탭 줄에는 지금 대화 탭과 `+`(새 대화)만. 넘기기 버튼(◀ ▶)도 숨긴다. **대화 목록 API 를 읽지 않는다**
- 켜면 예전처럼. 켜는 순간 목록을 읽는다
- 전체 목록은 `Ctrl+B` 오버레이(터미널과 같은 사이드바 부품)로 연다 — 프로젝트도 여기 보인다(아래)

## 2. 프로젝트 보이기

**실측(2026-10-02, 사용자 크롬 · 로그인 계정)** `[확정]`

- 프로젝트 목록 API `/backend-api/gizmos/snorlax/sidebar` → 200, 프로젝트 5개 (`items[].gizmo.{id, display.name}`)
- 원본 사이드바 프로젝트 링크 8개
- **우리 목록(`Ctrl+B`)에는 `~/chats` 묶음만** — 프로젝트가 하나도 안 보였다

**원인** `[확정 — 코드]`: 프로젝트의 대화는 기본 대화 목록 API 에 들어 있지 않다. 그래서 프로젝트 묶음은 처음에 늘 비어 있는데,
`chats.flatten` 이 **빈 묶음을 건너뛰었다.** 프로젝트를 처음 펼칠 때 대화를 읽어 오는 코드(`sidebar.toggleGroup` →
`chats.loadProject`)는 있었지만 누를 머리줄이 없어 닿을 수 없었다.

**바꾼 것**
- 프로젝트 묶음은 비어 있어도 머리줄을 낸다. **아직 안 읽은 프로젝트는 접힌 채, 개수 없이** 보인다
- 누르면 그 프로젝트의 대화를 읽어 펼친다. 읽었는데 비어 있으면 개수 0 으로 펼친다(다시 읽으러 가지 않는다)
- 터미널 사이드바와 시트의 `Ctrl+B` 목록이 같은 부품이라 둘 다 해당한다

### 범위 밖

- 시트 탭 줄을 프로젝트별로 묶는 것(엑셀의 통합 문서처럼)은 하지 않았다 — 기본이 숨김이 되어 쓰임이 적다
- 지금 대화가 어느 프로젝트에 속하는지 제목줄에 보이는 것은 하지 않았다
