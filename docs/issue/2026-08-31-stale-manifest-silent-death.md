# 새로고침해도 확장이 전혀 동작하지 않는다 (제거 후 재설치해야 살아남)

- 상태: **완화 적용됨** (2026-08-31)
- 관련 파일: `src/content/index.js`, `manifest.json`

## 증상

확장이 아무 반응이 없다. 터미널이 뜨지 않고, 콘솔에도 눈에 띄는 게 없다.
페이지를 새로고침해도 그대로다. **제거 후 다시 추가해야** 살아난다.

## 원인

크롬은 언팩 확장의 **매니페스트를 캐시한다.** 매니페스트에 파일을 추가한 뒤 확장을 다시 로드하지 않으면:

- 새로 추가된 파일은 **주입되지 않는다** (캐시된 매니페스트에 없으므로)
- 나머지 파일은 **디스크의 최신본**이 주입된다

이 상태에서 최신 코드가 새 파일의 심볼을 참조하면 그 자리에서 죽는다.
콘텐츠 스크립트는 파일마다 별개 스크립트라 하나가 죽어도 나머지는 계속 실행되지만,
`GT.config` 같은 전제가 사라진 채로 굴러가므로 결국 아무것도 못 그린다.

이번 사례를 재현한 결과:

```
ok    src/content/protocol.js
THROW src/content/config.js → ReferenceError: GT_DEFAULTS is not defined
GT.config 존재? false
```

`src/shared/defaults.js` 를 매니페스트에 추가한 것이 방아쇠였다.
`config.js` 첫 줄이 `const DEFAULTS = GT_DEFAULTS;` 라 즉시 죽었다.

**페이지 새로고침은 매니페스트를 다시 읽지 않는다.** 그래서 새로고침이 듣지 않았고,
제거 후 재설치는 당연히 다시 읽으므로 그것만 효과가 있는 것처럼 보였다.

## 제대로 된 해결 (사용자)

제거할 필요 없다.

```
chrome://extensions → gpt-skin 카드의 ↻ (다시 로드) → 페이지 새로고침
```

언제 ↻ 가 필요한가:

| 바꾼 것 | 필요한 조치 |
|---|---|
| `manifest.json` (파일 추가·권한·options_ui) | **↻ 필수** + 페이지 새로고침 |
| `src/background/service-worker.js` | **↻ 필수** |
| 콘텐츠 스크립트 · MAIN world tap 내용만 | **↻ 필수** + 페이지 새로고침 |
| 옵션 화면 (`src/options/*`) | 옵션 탭만 새로고침 |

**소스를 고쳤으면 항상 ↻ 다.**

### 정정 — 2026-09-01

이 문서의 첫 판은 "콘텐츠 스크립트 파일 내용만 고쳤으면 페이지 새로고침으로 대개 충분"이라고 적었다.
**측정해보니 틀렸다.** 크롬은 매니페스트만이 아니라 **파일 내용도 캐시한다.**

측정 방법과 결과:

1. `src/main/tap.js` 의 `harvest` 에 새 필드 `fiberEligible` 을 추가했다. 매니페스트는 건드리지 않았다.
2. 확장을 다시 로드하지 **않고** 대상 페이지만 새로고침했다.
3. 페이지 컨텍스트에서 MAIN world tap 에 직접 수확을 요청하고 응답을 봤다.

```js
window.postMessage({ __gpt_skin__: true, dir: 'i2m', kind: 'harvest', payload: {} }, location.origin);
// → 응답 payload: { total: 5, fiberHits: 3 }   ← fiberEligible 없음
```

`fiberEligible` 이 없다 = **옛 `tap.js` 가 그대로 실행 중이다.**
디스크의 파일에는 그 필드가 있고(`grep` 으로 확인), 매니페스트는 그대로였다.

`fiberEligible` 처럼 **새 코드에만 있는 관측 가능한 표식**을 넣어두면
"지금 도는 게 새 코드인가"를 이 방법으로 언제든 확인할 수 있다.

## 적용한 것 — 조용히 죽지 않게

`src/content/index.js` 맨 앞에 preflight 를 넣었다.
기대하는 모듈(`GT.config`, `GT.store`, … `GT_DEFAULTS`)이 하나라도 없으면 부팅을 멈추고:

- `console.error` 로 **무엇이 빠졌는지**와 **↻ 를 누르라는 것**을 찍는다
- 페이지 하단에 빨간 배너를 띄운다 — 콘솔을 안 봐도 보이게

배너 문구에 "제거 후 재설치할 필요 없다"를 명시했다. 이번에 헛수고한 부분이라서다.

## 왜 이게 또 생기나

이 확장은 파일이 여러 개고 전역 하나(`GT`)를 나눠 쓴다. 개발 중에 파일을 추가할 일이 계속 생기고,
그때마다 같은 함정이 있다. preflight 는 그 함정을 **없애지는 못하지만 5초 만에 알아채게** 만든다.
