# context — web-store-submission

## 사용자의 원 요청

> "이거 이제 web store에 올릴려고 하는데 전체 코드 점검해서 심사 통과할만한지 검사해줘."

점검 결과를 보고한 뒤, 후속 요청으로 다섯 가지를 지시했다.

> 1. 아이콘을 제로 그러 `>_` 이거 있지? 이거 모티프로.
> 2. 스토어용 이름, 설명문 만들어줘.
> 3. 초안 만들어줘. (개인정보처리방침)
> 4. 초안만들어줘. (권한 사유서 + 심사 노트)
> 5. 만들어줘. (배포 패키지 스크립트)

## 왜 이걸 지금 하는가

gpt-skin 은 그동안 **개인용 언팩 확장**으로 개발됐다. `chrome://extensions` 에서
압축해제 로드로만 써 왔고, 매니페스트의 description 에도 "개인용 언팩 확장" 이라고
적혀 있다. 이제 웹스토어에 공개 배포하려 하므로 그 전제가 바뀐다.

2026-09-04 전체 코드 점검에서 **코드 자체는 심사에 걸릴 것이 없음**을 확인했다.
원격 코드 실행 0건, `innerHTML` 0건, 외부 엔드포인트 0건, 텔레메트리 없음,
권한은 `storage` + 호스트 1개, accessToken 은 메모리 전용.

막는 것은 세 가지였다.

1. **아이콘** — OpenAI 육각 매듭 마크를 초록으로 바꾸고 `>_` 를 얹은 형태였다.
   CWS 의 Impersonation and Intellectual Property 조항에 걸린다.
2. **개인정보처리방침 부재** — 이 확장은 대화 내용을 읽는다. CWS 는 personal
   communications 를 다루면 방침 URL + 데이터 사용 공시를 필수로 요구한다.
3. **스토어용 문구 부재** — 이름·짧은 설명·상세 설명이 없다.

여기에 패키징 위생 문제가 겹친다. 폴더를 그대로 zip 하면 6.5MB 인데 실제 필요한 건
500KB 남짓이고, 나머지는 목업(`gpt-skin-tui.html` 2.5MB)·디자인 캔버스(`*.dc.html`)·
`docs/`·`test/`·`icons/source.png` 다. 특히 목업 파일은 ChatGPT UI 를 베낀 디자인
사본이라 심사관 눈에 띄면 불필요한 설명거리가 된다.

## 결정된 방향

코드는 건드리지 않는다. 브랜딩·공시·패키징 다섯 가지만 만든다.
아이콘은 `>_` 프롬프트 모티프로 완전히 새로 그린다.

## 기각된 대안

- **아이콘 색만 바꾸기** — 형태가 OpenAI 마크를 따르는 한 색을 바꿔도 같은 문제다.
  형태 자체를 버려야 한다.
- **개인정보처리방침 생략하고 제출** — 대화 내용을 읽는 이상 게시 자체가 막힌다.
- **비공개 API 쓰기 기능(이름변경·보관·삭제) 제거** — 제품 가치의 큰 부분이고
  CWS 가 직접 금지하는 항목도 아니다. 제거 대신 심사 노트에 명시하는 쪽으로 간다.
- **`:messup` 제거** — 사용자가 방금 "지금으로 충분함" 이라고 확정한 기능이다.
  제거 대신 심사 노트에 성격을 설명한다.

## 제약 / 합의 사항

- 기술 제약
  - 아이콘은 16px 에서도 읽혀야 한다. 기존 아이콘도 이 문제 때문에 16·32 는
    줄이지 않고 다시 그렸다(`tools/make-icons.py`). 새 모티프에서도 같은 규칙을 지킨다.
  - 개인정보처리방침 문구는 **실제 코드 동작과 일치**해야 한다. 추측으로 쓰지 않는다.
- 범위 제약
  - 실제 제출·계정 등록·방침 호스팅은 사용자가 한다.
  - 스크린샷·프로모 타일은 이번 범위 밖.
- 사용자 명시 선호
  - 아이콘 모티프는 `>_` (프롬프트).
  - 이 프로젝트 전반에서 확인하지 않은 것을 단정하지 않는다. 심사 관련 판단도
    "정책상 확실한 것" 과 "심사관 재량" 을 구분해 적는다.
